# Vows & Views

Responsive wedding and event planning website for Vows & Views.

## Pages

- `index.html` — homepage and services
- `portfolio.html` — celebration portfolio
- `about.html` — about and team

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server.

## Deploy to Netlify

This is a static website with no build step. In Netlify, import the GitHub repository and use:

- Build command: leave blank
- Publish directory: `.`

GSAP, Google Fonts, and portfolio photographs load from external CDNs/services.
